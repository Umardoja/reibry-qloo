# REIBRY Qloo

- **Project:** REIBRY Qloo
- **Parent concept:** REIBRY — From Saved to Done
- **Competition:** Qloo Agentic Hackathon 2026
- **Main goal:** culturally intelligent personal-memory recommendations
- **Planned integration:** Qloo Taste AI API
- **Intended demo:** user-confirmed preferences derived from saved Memories → Qloo recommendations → user-approved Ready Pack
- **Access and deployment status:** NOT VERIFIED
- **Submission deadline:** October 31, 2026, 4:45 AM Africa/Lagos

## Existing REIBRY capabilities inherited

This local variant starts from the existing REIBRY application and preserves its product and technical foundation, including Next.js/TypeScript, Supabase-backed authentication and storage, persistent Memories, capture and retrieval, the bounded Home agent, Life contexts, Plans/Ready Packs, existing AI-provider integrations, and Capacitor Android support.

This source snapshot has no Nebius adapter implementation: `src/lib/ai/nebius/` is empty and the current provider scripts/tests contain no Nebius implementation. No Nebius feature is claimed as inherited by this copy.

## Qloo work not yet implemented

There is no Qloo API client, Qloo credential/configuration, taste-profile synchronization, Qloo-backed recommendation, or Qloo-enriched Ready Pack in this project yet. The intended flow is a planning target only. No Qloo account access, API behavior, or deployment is verified.

REIBRY Qloo remains an independent development copy of the existing REIBRY project. Attribution to the parent project is preserved; the UI branding has not been changed.
